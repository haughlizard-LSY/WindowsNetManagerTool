# 网卡管理器 NetManagerTool

**Windows 本地网卡配置管理工具** —— 查看/切换本机网卡的 IP 配置。

日常场景：笔记本在「办公室静态 IP」与「家里 DHCP」之间来回切换，传统做法是每次
手动打开控制面板 → 改 IP → 填网关 → 改 DNS，繁琐且易错。本工具把每块网卡的配置
保存为**命名档案**，需要时点一下即可切换，并带安全回滚与操作日志。

## 一、功能特性

1. **查看网卡**：列出本机所有网卡（有线/WLAN/虚拟），显示当前**生效配置**：
   - 连接状态（已连接/已断开/已禁用）、MAC 地址、网卡描述
   - IP 获取方式（静态 / DHCP）
   - 全部 IPv4 地址、默认网关、DNS 服务器
   - 支持「刷新」随时重新读取（快捷键 F5）

2. **多套配置档案**：每块网卡可保存多个命名档案（如「办公室-静态IP」「家里-DHCP」）：
   - 档案模式：**静态 IP** 或 **DHCP 自动获取**
   - 静态档案支持 **多个 IP 地址**（Windows 网卡本就支持多地址）
   - 含默认网关、首选/备用 DNS、备注
   - 档案数据**本地持久化**，与 Windows 系统配置完全分离，随时增删改

3. **保存当前配置为档案**：选中网卡一键把「当前系统生效配置」抓取为档案
   （适合想留个底、或从当前配置微调成新档案的场景）。

4. **一键应用/切换**：
   - 选中网卡 → 选择档案 → 点「应用选中档案」即写入系统并立即生效
   - 应用前**二次确认**（切换会中断网络，提示明确）
   - 应用前自动**快照** → 应用后自动**校验** → 失败**自动回滚**到原配置
   - 「预览命令」可查看将执行的 PowerShell 命令（不实际执行）
   - 全程写入 **apply.log** 便于排障

5. **安全与体验**：
   - 启动自动请求 UAC 管理员权限（无弹控制台窗口，不闪黑框）
   - 所有 Qt 槽加异常护栏：任何错误弹窗提示 + 写 crash.log，不静默崩溃
   - 支持中文/英文 Windows 网卡信息解析

## 三、快速开始

### 方式 A：使用打包好的 exe（推荐，免安装）

```
dist\NetManagerTool.exe
```

双击运行 → 弹 UAC 点「是」→ 进入主界面。把 exe 拷到任意 Win10/11 电脑即可用。
首次启动为单文件自解压，需等 3~8 秒属正常。

### 方式 B：源码运行（开发/调试）

```bash
# 1) 安装依赖
pip install -r requirements.txt        # 内容仅一行：PySide6

# 2) 启动
python main.py                          # 非管理员会自动弹 UAC 提权
```

调试技巧：
```bash
python main.py --no-elevate             # 跳过 UAC，以当前权限直接跑（应用按钮会被禁用）
python main.py --data-dir=.\data        # 把数据库放到指定目录（便携测试用）
```

## 四、界面与使用说明

### 4.1 界面总览

```

│ │ …         │ │ 配置档案                                          │

│              │ ┌─────────────────────────────────────────────────┐ │
│              │ │ 档案名称      │ 配置                 │ 备注      │ │

│              │ └─────────────────────────────────────────────────┘ │
```

### 4.2 查看网卡当前配置

1. 左侧点击任意网卡 → 右侧上方即显示其**当前生效**配置。
   > 「当前配置（只读）」表示此处仅展示系统现状，改动请通过下方档案进行。
2. 网络变化后可点「刷新」（或按 F5）重新读取。

### 4.3 新建配置档案

1. 左侧选中目标网卡 → 下方点「**新增档案**」。
2. 填写：
   - **档案名称**（必填，如 `办公室-静态IP`）
   - **获取方式**：
     - `静态 IP`：可填多行地址。第一行 = 主 IP，其余自动作为附加 IP；
       每行右侧下拉选择前缀（0~32）。再填默认网关、DNS（可留空）。
     - `DHCP`：忽略下方静态字段。
   - 备注（可选）
3. 「保存」后出现在档案表中。

### 4.4 编辑 / 删除档案

- 表格里选中档案行 → 「编辑」修改内容，或「删除」移除。
- 删除仅移除本工具保存的档案记录，**不影响**当前系统网络配置。
- 同一网卡下档案名称不可重复。

### 4.5 把当前系统配置存成档案

「💾 保存当前配置为档案…」会把所选网卡**当前生效配置**自动预填到新建对话框：
- 当前为 DHCP → 档案自动选「DHCP」
- 当前为静态 → 自动带入全部 IP、网关、DNS（自动过滤 169.254 链路本地等临时地址）

填个名称保存即可 —— 适合先留底，或以此为基础改出新档案。

### 4.6 应用 / 切换档案（核心操作）

1. 选网卡 → 选档案行 → 点「**▶ 应用选中档案**」。
2. 弹出确认框（列出将设置的 IP/网关/DNS，并提示会短暂断网）→ 点「Yes」。
3. 程序执行并**校验**结果，弹窗反馈：
   - ✅ **配置已成功应用并生效**
   - ❌ 失败 → 自动回滚原配置，并给出原因
4. 不确定时先点「**预览命令**」查看将执行的 PowerShell 命令，不会改动系统。

> 应用需要管理员权限。若当前窗口非管理员，顶部会出现黄色横幅并附
> 「以管理员身份重启」按钮；标题栏会明确显示 `[管理员]` 或 `[普通权限…]`。

## 五、配置档案详解

| 字段 | 说明 |
|---|---|
| adapter_name | 绑定网卡名（如 以太网/WLAN） |
| mode | `static` 静态 / `dhcp` 自动获取 |
| ip / prefix | **主地址** IP 与前缀长度（如 10.10.100.24 / 24） |
| extra_ips | **附加地址**列表（每项形如 `192.168.1.5/24`） |
| gateway | 默认网关（仅静态；必须与主地址同网段才会被 Windows 接受） |
| dns1 / dns2 | 首选/备用 DNS |
| note | 备注 |

校验规则：IP 必须合法、前缀 0-32、地址不得重复、DNS 不能与备用相同等，
对话框保存时会即时校验并拦截。

## 六、权限模型（重要）

| 操作 | 是否需要管理员 |
|---|---|
| 查看网卡 / 当前配置 | 否 |
| 新增/编辑/删除档案 | 否（纯本地记录） |
| **应用 / 切换档案** | **是** |

权限处理策略：
- 源码启动：检测到非管理员 → 自动 UAC 提权重启自身；若拒绝 → 以**只读模式**
  继续运行（可查看/建档，应用按钮不可用并给出提示）。
- exe（`--uac-admin`）：双击即弹 UAC，**必须**同意才启动，保证应用功能始终可用。

## 七、数据存储与日志

| 内容 | 位置 |
|---|---|
| 配置档案数据库 | `%APPDATA%\NetManagerTool\profiles.db`（SQLite） |
| 应用/切换操作日志 | `%APPDATA%\NetManagerTool\apply.log` |
| 崩溃/异常日志 | `%APPDATA%\NetManagerTool\crash.log` |

若 `%APPDATA%` 不可写，数据库自动回退到 `%LOCALAPPDATA%` → 用户主目录
`~/.netmanager/`，保证任何环境可启动。

## 九、技术实现

### 9.1 读取网卡（双通道自动降级）

| 通道 | 命令 | 特点 |
|---|---|---|
| PowerShell（主） | `Get-NetAdapter` / `Get-NetIPAddress` / `Get-NetIPConfiguration` / `Get-DnsClientServerAddress`，输出 JSON | 信息全（含 MAC、描述、DHCP 状态） |
| netsh（降级） | `netsh interface ipv4 show ...` | 兼容无 PowerShell/CIM 环境；中英文标签均可解析 |

### 9.2 写入（应用档案）

使用 PowerShell NetTCPIP 模块，流程：
```
Set-NetIPInterface -Dhcp Disabled/Enabled
清理残留默认路由 → 移除旧 IPv4（避免冲突）
逐个 New-NetIPAddress（主地址 + 附加地址）
New-NetRoute 建立默认网关
Set-DnsClientServerAddress 配置 DNS
```
安全性：
- 执行脚本 `$ErrorActionPreference='Stop'`：任何一步失败立即中止（避免假成功）；
- 应用前读取配置作**快照**，校验失败自动**回滚**；
- 应用后延迟重试校验，容忍网络栈刷新时序。

### 9.3 界面与线程

- PySide6 (Qt6)；耗时操作（读网卡/应用）放 QThread，不阻塞界面；
- 所有 Qt 槽经 `guard_slot` 包裹，异常写 crash.log 并弹窗而非闪退；
- 子进程统一 `CREATE_NO_WINDOW`，从 GUI 调用 powershell/netsh **不弹黑窗口**。

## 十一、打包为单文件 exe

### 一键打包

```
双击 build_exe.bat
```

脚本自动检查 Python / PySide6 / PyInstaller → 运行打包 → 产物
`dist\NetManagerTool.exe`（**约 28 MB**）。

### 体积优化说明

打包使用 `nicmanager_slim.spec`：只保留实际用到的 `QtWidgets/QtGui/QtCore`
运行时，剔除 QtWebEngine(194MB)/QML/PDF/OpenGL/Network 等无关模块，
因此单文件从默认方案的 ~244MB 降到 **~28MB**。spec 内含：
- `--onefile`：单文件；首次启动自解压，慢几秒属正常
- `--windowed`：无黑色控制台
- `--uac-admin`：双击即弹 UAC 并以管理员运行
- 图标 `icon.ico`

若需更改裁剪范围，编辑 `nicmanager_slim.spec` 中的
`_EXCLUDE_BIN_FRAGMENTS` 列表即可，或运行 `tools/gen_slim_spec.py` 重新生成。

> 注：杀毒软件对 PyInstaller 产物偶有误报（未签名程序常见），属正常现象，
> 添加信任即可。正式分发建议使用代码签名证书。

## 十二、常见问题排查（FAQ）

### Q1 双击 exe 弹 UAC 后没反应/一闪而过？
新版已内置崩溃上报：任何启动异常会**弹窗**并把详情写入
`%APPDATA%\NetManagerTool\crash.log`。请查看该文件内容后反馈。
若为旧版本问题（UAC 提权重启参数错误导致子进程秒退）已修复。

### Q2 应用档案提示「命令成功但校验未通过」？
历史 bug（网关残留路由冲突 + 脚本吞错）已修复：
- 应用前自动清理残留默认路由，网关改用独立 `New-NetRoute`；
- 执行改用 Stop 严格模式，失败立即中止并回滚；
- 请查看 `apply.log` 中 `[verify]` 行的比对详情。

### Q3 应用后网络断了/上不了网？
切换 IP 配置会**短暂断网**属正常；若新配置不正确（如网关与 IP 不同网段），
程序校验失败会自动**回滚**到应用前配置。极端情况下也可在 Windows
`设置 → 网络 → 更改适配器选项` 中手动恢复，或让网卡改用 DHCP。

### Q4 找不到档案了？
数据库在 `%APPDATA%\NetManagerTool\profiles.db`。档案以**网卡名**绑定；
若 Windows 网卡被改名/重装，旧档案不会自动出现在新名下（见已知限制）。

### Q5 提示需要管理员权限但我是管理员？
当前窗口可能运行在**未提权**实例。看标题栏：`[管理员]` 为已提权；否则用顶部
横幅「以管理员身份重启」，或关闭后重新双击 exe。

### Q6 杀毒软件报毒？
PyInstaller 单文件 + 未签名常见误报。添加信任/排除项即可；如需分发请代码签名。

### Q7 PowerShell 弹窗/黑框闪烁？
已通过 `CREATE_NO_WINDOW` 消除。若仍出现，请确认运行的是最新版本代码或 exe。

### Q8 网卡名显示乱码？
程序已做 UTF-8/GBK 自适应解码与中英文解析；若特定环境异常，请提供
`%APPDATA%\NetManagerTool\crash.log` 或界面截图反馈。

## 十三、已知限制

- 目标平台为 **Windows**；仅管理 **IPv4**（IPv6 仅展示链路本地地址）。
- 档案以**网卡名**绑定；网卡改名后需手动重绑（当前版本未提供一键迁移）。
- 静态档案的网关须与主地址同网段（Windows 强制），跨网段会被拒绝并回滚。
- netsh 降级通道不提供 MAC/网卡描述（PowerShell 通道提供）。
- 不做网卡启停（禁用/启用）、WLAN 密码管理等（非本期范围）。
